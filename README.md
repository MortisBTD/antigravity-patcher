# Antigravity Patcher

Снимает экран блокировки «your account is not eligible for Antigravity, because it is
not currently available in your location» на старте Google Antigravity.

Патч локальный: правится `resources\bin\language_server.exe`, который отдаёт сам веб-интерфейс.
Серверную проверку аккаунта никто не отменяет — приложение просто перестаёт показывать
экран «ты не в той стране» и пускает в рабочий интерфейс.

## Что внутри

```
patcher.pyw     GUI-патчер (tkinter, без зависимостей)
Запустить.cmd   запуск без консоли
TECH.md         что именно правится и почему
```

## Как пользоваться

1. Запустить `Запустить.cmd`.
2. «Пропатчить» — патчер сам найдёт установленный Antigravity, закроет его, сохранит
   `language_server.exe.orig` и применит патч. После записи перепроверяет CRC и размер файла.
3. «Запустить Antigravity».
4. Включить VPN и войти в аккаунт.

«Откатить» возвращает оригинальный файл из `language_server.exe.orig`.

## Ограничения

* Патч привязан к версии 2.24.0 и к конкретным строкам в бандле. После обновления
  Antigravity нажать «Пропатчить» заново; если якоря не найдутся, патчер скажет, что
  сборка не поддерживается, и ничего не тронет.
* VPN всё равно нужен: патч убирает только экран блокировки, не саму сетевую проверку.
* Windows, Python 3.9+ с tkinter (для GUI). Для самой правки хватило бы и просто Python.

## Как это работает

Коротко: интерфейс Antigravity — это `main.js` внутри zip-архива, вшитого в
`language_server.exe` (секция с 304 записями, entry `main.js`, deflate). Патчер находит
EOCD, считает базу архива, распаковывает бандл, меняет два места, сжимает обратно
(9-й уровень укладывается в исходный csize с запасом ~10 КБ), правит CRC/размеры в
локальном заголовке и в центральной директории. Подробности — в `TECH.md`.
